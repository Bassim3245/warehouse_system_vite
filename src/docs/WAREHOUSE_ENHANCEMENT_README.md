# نظام تعزيز توريد المواد - دليل المستخدم

## نظرة عامة
تم تطوير نظام متكامل لتعزيز توريد المواد في المخازن مع ربطه بـ API البحث `SearchStoreData` لضمان مرونة وبساطة الاستخدام.

## الميزات الجديدة

### 1. نظام تعزيز التوريد (ImportData.js)
- **البحث الذكي**: بحث بالرقم الرمزي، اسم المادة، أو المواصفات الفنية
- **التحقق من وجود المواد**: التأكد من أن المادة معرفة مسبقاً في المخازن
- **اختيار المخزن**: إمكانية تحديد المخزن المطلوب قبل البحث
- **معلومات شاملة**: عرض الكمية الحالية والحد الأدنى للمخزون
- **تأكيد العملية**: نافذة تأكيد تعرض جميع تفاصيل التوريد

### 2. تحسينات نموذج إضافة المواد (FormModel.js)
- **التحقق من التكرار**: فحص تلقائي لوجود مواد مكررة
- **التحقق الفوري**: عرض تنبيهات فورية عند إدخال بيانات مكررة
- **تحسين التحقق**: تحقق محسن من صحة البيانات المدخلة
- **واجهة محسنة**: مؤشرات بصرية للحالة والأخطاء

### 3. تحسينات البحث والفلترة (storeData.js)
- **بحث متقدم**: بحث بالرقم الرمزي، الاسم، والمواصفات
- **فلاتر متعددة**: فلترة حسب حالة المادة ومستوى المخزون
- **مسح الفلاتر**: إمكانية مسح جميع الفلاتر بنقرة واحدة
- **واجهة محسنة**: تنظيم أفضل لعناصر البحث والفلترة

## كيفية الاستخدام

### تعزيز توريد المواد
1. **اختيار المخزن**: حدد المخزن المطلوب من القائمة المنسدلة
2. **البحث عن المادة**: 
   - اكتب الرقم الرمزي أو اسم المادة أو جزء من المواصفات
   - ستظهر النتائج تلقائياً مع معلومات الكمية الحالية
3. **اختيار المادة**: انقر على المادة المطلوبة من نتائج البحث
4. **إدخال تفاصيل التوريد**:
   - الكمية المستوردة
   - سعر الوحدة
   - اسم المورد
   - ملاحظات (اختياري)
5. **تأكيد العملية**: راجع التفاصيل في نافذة التأكيد واضغط "تأكيد التوريد"

### إضافة مادة جديدة
1. **إدخال البيانات الأساسية**:
   - الرقم الرمزي (مطلوب)
   - اسم المادة (مطلوب)
   - وحدة القياس (مطلوب)
   - الحد الأدنى للمخزون (مطلوب)
2. **التحقق التلقائي**: سيتم فحص وجود مواد مكررة تلقائياً
3. **إدخال البيانات الإضافية**:
   - المواصفات الفنية
   - المنشأ
4. **حفظ المادة**: اضغط "حفظ" بعد التأكد من صحة البيانات

### البحث والفلترة
1. **البحث النصي**: استخدم حقل البحث للبحث بأي معلومة
2. **فلترة حسب الحالة**: اختر حالة المادة من القائمة
3. **فلترة حسب المخزون**:
   - جميع المواد
   - مواد منتهية الصلاحية
   - مواد أقل من الحد الأدنى
   - مواد متوفرة
4. **مسح الفلاتر**: استخدم زر "مسح الفلاتر" لإعادة تعيين جميع الفلاتر

## التقنيات المستخدمة

### API المستخدم
- **SearchStoreData**: للبحث عن المواد في المخازن
- **importMaterial**: لتسجيل عمليات التوريد الجديدة
- **storeDataRegister**: لإضافة مواد جديدة
- **StorDataEdit**: لتعديل بيانات المواد

### المكونات الرئيسية
- **Material-UI**: للواجهة والمكونات البصرية
- **React Hooks**: لإدارة الحالة والتأثيرات
- **Axios**: للتواصل مع الخادم
- **React-Toastify**: للإشعارات
